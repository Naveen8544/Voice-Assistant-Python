# AI Voice Assistant (Python)

## Overview

This is a Python-based AI Voice Assistant that listens to voice commands and performs different tasks using speech recognition and text-to-speech.

## Features

* Voice Recognition
* Text-to-Speech
* Greeting Based on Time
* Wikipedia Search
* Google Search
* Open YouTube
* Open Facebook
* Open Stack Overflow
* Play Music
* Tell Current Time
* Exit with Voice Command

## Technologies Used

* Python 3.11
* SpeechRecognition
* PyAudio
* pyttsx3
* Wikipedia
* Webbrowser
* OS Module

## Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/Voice-Assistant-Python.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the project

```bash
python index.py
```
